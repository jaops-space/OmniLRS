In the present folder there is the code and the necessary files for the solar panel and lunar dust classes.


The Lunar_Dust.py and Panel_Class.py are the two differents classes developed. 

The two notebooks lunar_dust_test.ipynb and solar_panel_test.ipynb are the two notebooks used to test the two classes and which show how they work in a simple lunar environment.

moon_environnement.usdc --> evironment used for testing.  It is introduced in the simulation by the notebooks 

simplified_surface_solar_panel.usd --> simple solar panel used for testing in the solar_panel_test notebook

Rover_e_panneau_orig.usd + solo_solar_pannel.usd --> two usd used to model the rover + it's solar panel. It's necessary that they are in the same folder for them to work together, if the solar panel it's not showing then there's a problem with solo_solar_pannel.usd name or location

solar_panel_final_turned.usd --> usd used to test the accumulation of dust in the Real Time scenario for Lunar Dust
